# BUNI Transit-INT

**Live:** https://absurdsenapiii.github.io/buni-transit/

An open-source intelligence console for Singapore's streets: rain at every bus stop, free taxis, located lightning, the 2-hour forecast, air temperature and live traffic cameras, correlated on a 3D map. Every figure comes straight from official open data and carries its observation time. Nothing is predicted or invented, and no people or vehicles are tracked.

This repository holds only the built static site that GitHub Pages serves.

## Data

- Land Transport Authority and Meteorological Service Singapore (NEA), via [data.gov.sg](https://data.gov.sg), under the [Singapore Open Data Licence](https://data.gov.sg/open-data-licence).
- Basemap: [OpenFreeMap](https://openfreemap.org), © [OpenMapTiles](https://openmaptiles.org), © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors.
